How We're Different

Existing bots are black boxes — they generate plausible-sounding text but can't prove their answers are grounded in real data. ResolveFlow enforces compliance at the code level using deterministic DAG traversal, not prompt engineering.

How We Solve It

Every action flows through a Policy Graph Validator. The LLM cannot issue a refund unless it has verified eligibility, checked for duplicates, and passed a hard-coded DAG gate — then the result is sealed with an HMAC evidence receipt.

Unique Selling Proposition

"Glass-Box AI" — Every customer-facing claim is cryptographically bound to the exact tool output via tamper-evident HMAC receipts. The UI shows a "✓ Verified" badge. A reviewer can prove no fact was hallucinated.

PROCESS FLOW

How It Works

01. Intent
02. Policy RAG
03. DAG Guard
04. Output

Step 1: The system receives a message and runs concurrent intent detection via Gemini-Flash-Lite.

Step 2: Based on intent, it fetches precise business rules using ChromaDB and Self-RAG.

Step 3: A hard-coded Directed Acyclic Graph (DAG) validates that the user meets all policy requirements.

Step 4: The verified result is sent to the frontend via an SSE stream, rendering interactive widgets.

AI/ML Modules & APIs

Gemini Dual-Model Split: Gemini 2.5 Flash for policy reasoning, and Lite for high-speed intent classification. Integrated with CRAG (Corrective RAG).
